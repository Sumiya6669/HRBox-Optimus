# Курсы и тестирование — что применить

## 1. SQL

Supabase → **SQL Editor** → вставить содержимое
`supabase/migrations/0015_courses_lessons_tests.sql` → **Run**.

Порядок, если предыдущие ещё не применяли: `0013` → `0014` → `0015`.

Что создаётся:

- `course_lessons` — уроки курса (видео, документ, текст, ссылка);
- `lesson_progress` — прохождение уроков; прогресс курса пересчитывает триггер;
- `course_tests`, `test_questions`, `test_options`, `test_attempts` — тесты;
- функции `complete_lesson`, `start_test_attempt`, `submit_test_attempt`,
  `course_stats`;
- бакет `course-media` для видео (500 МБ, MP4/WebM/MOV/PDF).

Отдельно проверьте в Supabase → **Storage**, что бакет `course-media` появился.
Если проект создавался давно, у него может быть свой глобальный лимит на размер
файла: Settings → Storage → *Upload file size limit*. Его надо поднять до 500 МБ,
иначе большие ролики отклонит сам сервис, а не бакет.

## 2. Как наполнить курс

**Администрирование → Курсы → «Уроки и тест»** у нужного курса.

Вкладка **Уроки**:

1. «Добавить урок» → название → тип «Видео».
2. Перетащите файл в область загрузки или нажмите «Выбрать файл».
3. Галочка «Обязательный урок» — влияет на процент прохождения. Снимите её для
   дополнительных материалов.
4. Порядок уроков меняется стрелками.

Вкладка **Итоговый тест**:

1. «Создать тест» — сразу с настройками по умолчанию (порог 80 %, 15 минут,
   3 попытки), их можно поменять тут же.
2. «Добавить вопрос» → текст → варианты → галочками отметить верные.
3. «Показывать верные ответы после сдачи» по умолчанию выключено — иначе первый
   сдавший разошлёт ключ остальным.

## 3. Как это видит сотрудник

**Кабинет → Обучение → курс**: слева программа курса, справа материал. Кнопка
«Начать» открывает видео (до нажатия ролик не грузится — чтобы не съедать
трафик на мобильном). Урок отмечается пройденным по окончании ролика или
кнопкой «Отметить пройденным».

Итоговый тест — последним пунктом программы. Он открывается только после всех
обязательных уроков. Экран теста идёт без бокового меню: таймер, полоса
вопросов, «Далее», в конце — результат с процентом и порогом сдачи.

## 4. Метрики

- **Администрирование → Курсы** — сводка по всему обучению: назначено, в
  процессе, завершили, средний прогресс, процент сдачи тестов.
- **Уроки и тест** внутри курса — те же метрики по одному курсу.
- **Кабинет → Обучение** — личный прогресс сотрудника (теперь это реальная
  цифра, а не проставленная вручную).
